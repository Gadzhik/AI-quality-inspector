# Аудит датасета перед обучением

## Зачем

На этом проекте авторский сплит датасета LOCBEEF оказался испорчен: 133 тестовых
кадра имели ТОЧНЫЙ дубликат в обучающей выборке, а у 97% был почти-дубликат.
Модель показала 99.9% — цифра, не значащая ничего. Такие датасеты собирают
сериями снимков одного образца, и случайное разбиение растаскивает соседние кадры
одной серии по разным сплитам.

**Правило: высокая точность на чужом сплите — повод для проверки, а не для радости.**

## Порядок действий

### 1. Проверить утечку

```bash
python .claude/skills/dataset-audit/check_leakage.py <train_dir> <test_dir>
```

Скрипт считает перцептивные хеши (dHash) и для каждого тестового кадра ищет
ближайший обучающий. Интерпретация:

| Расстояние Хэмминга | Что значит |
|---|---|
| 0 | точный дубликат — утечка гарантирована |
| ≤ 3 | тот же кадр с другим сжатием/кропом |
| ≤ 8 | соседний кадр той же серии |
| > 16 | разные образцы |

Если доля кадров с расстоянием ≤ 8 превышает ~10%, авторский сплит использовать
нельзя.

### 2. Построить своё разбиение по кластерам

Кластеризуем почти-дубликаты и раскладываем по сплитам ЦЕЛЫМИ кластерами, чтобы
один физический образец не попал сразу в обучение и в тест.

**Кластеризовать только leader-методом, не union-find.** Транзитивное склеивание
(«A похож на B, B похож на C») стягивает всё в один кластер: на этом датасете
union-find дал 83 кластера на 3268 кадров, и обучаться стало не на чем. При
leader-подходе кадр сравнивается только с лидерами уже созданных кластеров —
получилось 425 кластеров.

Готовая реализация: `split_by_clusters()` и `cluster_duplicates()` в
`train_freshness.py`.

### 3. Найти независимую проверку

Свой hold-out показывает только то, что модель выучила ЭТОТ датасет. Нужен второй
набор — другая лаборатория, камера, освещение. Разрыв между ними и есть настоящий
результат: здесь было 100% на своём hold-out против 65% на чужих фото.

## Чего ещё искать в кадрах

- **Выжженный таймштамп / служебные надписи.** Если классы сняты в разное время,
  модель прочитает цифры вместо предмета. Срезать полосу с таймштампом.
- **Постоянный фон.** Тарелка, стол, подложка — модель выучит их. Обрезать до
  предмета.
- **Разный баланс белого у классов.** Нормализовать по белому фону кадра.
