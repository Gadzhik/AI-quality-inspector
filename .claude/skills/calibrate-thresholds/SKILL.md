# Калибровка цветовых порогов по замеру, а не на глаз

## Зачем

В этом проекте угаданные пороги ошибались три раза подряд, и каждый раз замер
показывал контринтуитивную причину:

1. «Мясо — это красное» → на самом деле **красная кафельная плитка** на стене
   краснее и больше любой туши. Отличие в насыщенности: плитка S ~173-205,
   мясо S ~50-120. И в текстуре: у плитки дисперсия лапласиана ~4, у мяса 44-267.
2. «Сгусток — тёмное красное пятно» → под это же описание попал **бордовый фартук
   мясника** (S ~209, V ~40). Отличие в размере (фартук даёт пятно 160-170 тыс. px
   против 17-65 тыс. у сгустка) и в локальном контрасте с окружением.
3. «Поверхность туши — мясо» → у баранины поверхность это **белый жир**:
   R-G ~-1..+2, S ~13-16, по цвету неотличим от серой кофты рабочего. Красные
   участки годятся только как зёрна для карты плотности.

**Правило: перед любым порогом — замер. Один прогон скрипта дешевле, чем день
отладки детектора, который ловит стену.**

## Порядок действий

```bash
python .claude/skills/calibrate-thresholds/sample_pixels.py production.mp4 --frame 120
```

Скрипт сохраняет кадр с пронумерованной сеткой точек и печатает по каждой точке
R-G, G-B, S, V и дисперсию лапласиана. Дальше:

1. Открыть сохранённый кадр (`Read`) и сопоставить номера с объектами.
2. Выбрать признаки, которые РАЗДЕЛЯЮТ целевой объект и мешающий фон. Обычно
   работает не сам цвет, а сочетание: насыщенность + текстура + размер.
3. Прописать пороги в `src/meat_crop.py` (`meat_mask`) или `src/box_refine.py`
   (сигнатура сгустка) — там же оставить замеренные числа в комментарии, чтобы
   следующий человек видел, откуда они взялись.
4. Проверить на регрессию: `python main_freshness.py` (фото) и тест рамок на
   ground truth манифесте.

## Точечный замер конкретных координат

```bash
python .claude/skills/calibrate-thresholds/sample_pixels.py frame.jpg --points 880,300 250,200 1500,700
```

## Что мерить всегда

| Признак | Что различает |
|---|---|
| `R-G`, `G-B` | мясо vs белый стол (G-B ~33-38) и синие перчатки |
| `S` (насыщенность) | мясо (50-120) vs кафель (173-205) и фартук (~209) |
| `V` (яркость) | сгусток (35-60) vs нормальная ткань |
| дисперсия лапласиана | текстура: мясо 44-267 vs гладкие поверхности 2-8 |
| площадь пятна | сгусток (17-65 тыс. px) vs крупный посторонний объект |
